# AURA Haute Couture — Home Page Starter

A responsive Next.js + TypeScript + Tailwind CSS starter based on the AURA luxury fashion reference.

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally
1. Extract this ZIP.
2. Open the extracted `aura-haute-couture` folder in VS Code.
3. Open Terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Visit `http://localhost:3000`.

## Included in this first stage
- Responsive luxury home page
- Announcement bar, responsive header, mobile navigation drawer
- Hero section, signature collections, product cards
- Add-to-bag and wishlist interactions (in-memory starter behavior)
- Brand story, seasonal banner, testimonials, newsletter interaction, footer
